# 第一眼深井 · 可走动 3D 样段 v01

日期：2026-09-05。用户认可首张概念图后同意继续，以小步可见成果验证体验。

## 入口与目标

- 入口：`/descent.html`，沿用静态 HTTP 服务。
- 从狭窄矿道走出，经同伴停步提示，看到巨大地下设施与逐步亮起的灯窗。
- 约 40 米可行走路线，包含隧道、转角、临渊栈道与观测台。
- 第一版验证移动、镜头、空间尺度与声音；人物和建筑仍为程序化占位模型。
- 参考图：[第一眼深井 v01](../../assets/concepts/first-descent-v01.png)。

## 实现边界

- 独立静态页与 Three.js WebGL 2 场景，使用固定版本 0.185.1，本地 vendor 文件附 MIT 许可证。
- 角色与镜头均在真实三维坐标中移动；矿道墙体产生遮挡，走出后露出远处的几何建筑。未将概念图贴成背景冒充 3D。
- 同一条路线中心线用于生成栈道和角色碰撞约束。镜头单独检查隧道障碍，避免穿墙。
- WASD / 方向键、拖动视角、触控方向键；失焦与弹出参考图时释放输入。
- 世界状态只在页面内存中存在，不读取或修改正式游戏存档。
- 同伴移动、停步、手势和字幕是固定事件，不是 AI Agent。环境声使用 WebAudio，无语音模型或外部音频请求。
- 大规模建筑实例化合批，阴影仅用于近处角色；屏幕像素倍率有限制。
- 此浏览器样段用于快速评价空间体验，不代表已经建立 Unreal 正式制作管线。

## 验证

`node test/descent-browser.cjs`。测试使用独立浏览器会话，验证：3D 初始化、实际键盘移动、出洞事件、灯窗变化、同伴停步、护栏与终点限制、镜头拖动与避墙、参考图暂停、重走、手机触控、失焦停止、正式存档不变、图形中断提示与刷新恢复。

截图写入 `output/descent-entry.png`、`output/descent-reveal.png`、`output/descent-overlook.png`、`output/descent-mobile.png`，仅作本次验收证据。

## 用户评审重点

1. 走出洞口时是否明显感觉空间被打开？
2. 相机距离、移动速度、环顾手感是否舒服？
3. 最值得先细化的是场景材质、灯光、人物，还是路线与尺度？

下一步根据实际体验反馈只改善一个最影响感受的方面。
