# 检修站 · 第一场交锋

> 历史记录（2026-09-10）：以下内容记录当时的样片、实现与评价。当前美术目标见[最新规范](../ArtDirection/art-direction-v1.md)；本文旧工业主导、检修工外观或永夜要求不再作为后续制作标准，原有测试与实现状态仍按原日期理解。

这一轮响应用户提出的《艾尔登法环》式战斗感觉，检验读招、出手承诺、闪避时机和体力管理。角色、工业守井者、程序动画及音效均为本项目原创原型；没有复制该游戏资产。

## 体验

执行 `unreal/AshWell/Scripts/launch_combat.command`。检修平台位于原深井背景中，原 FirstDescentIntro 和 V02Final 资产保留。按 E 送电，灯依次亮起、设备启动，同伴退后，守井者苏醒。供电闸有世界空间标记；近身用锤头击中守井者也会触发遭遇。击败守井者获胜，被击倒后按 R 立即重来。

WASD 移动，鼠标观察，Tab 锁定，左键攻击，空格短闪，无方向时后撤。左 Shift 慢行，Esc 暂停。敌方抬锤可观察，最后阶段固定朝向；重击结束后留出反击时间。

## 当前规则

- 玩家生命100、体力100；攻击消耗24、短闪消耗28。动作后延迟恢复，闲置每秒恢复26。
- 攻击0.833秒，其中0.30–0.45秒判定可见锤头扫掠；每次攻击最多命中一次，伤害40。
- 短闪0.583秒，0.07–0.37秒提供无敌窗口，移动受场景碰撞阻挡。动画目前是低身闪身，完整翻滚另行打磨。
- 守井者240生命；蓄势1.05秒、重击0.22秒、恢复1.25秒，一次命中伤害35。蓄势最后0.35秒不再追踪朝向。
- 攻击后段可以短暂缓存下一次攻击或闪避；攻击前段不能直接取消成闪避。敌人恢复期受击不会提前结束破绽。
- 锤头挂接忽略导入骨骼的100倍单位换算尺度，以世界厘米保持尺寸与攻击轨迹一致。

## 实现与验证

`Source/AshWell/AshWellCombatCharacter.*` 提供玩家战斗与局部诊断；`AshWellWarden.*` 提供敌人状态、程序动作和受击；`AshWellCombatArena.*` 提供平台碰撞、供电及设备反馈。现有 HUD/游戏模式按运行参数选择战斗分支。

`SourceAssets/CombatCharacters` 保留五个动作、Blender源文件和FBX往返验证；动作已导入UE并核对时长及骨架。`SourceAssets/CombatAudio` 包含三个原创48kHz短音效；`SourceAssets/CombatGeometry` 包含倒角装甲块。

`-CombatQA` 会调用同一套玩家移动、攻击和闪避接口跑一个自动交锋，仅供开发验证，不授予无敌或额外伤害。诊断输出为 `Saved/Automation/combat-runtime.json`，真实游戏截图输出为 `Saved/Screenshots/Combat/`。最终验证结果见项目 `output/ue-combat-*.json`。

当前验证：真实游戏中观察到打击、受击、死亡、闪避窗口及体力限制；保留体力并在恢复期反击的自动回合约42秒取胜，6次有效命中、12次无敌窗口避伤，所有存活采样均在地面上且生命/体力未越界。手动移动、短闪和Tab锁定也已产生运行时状态变化。没有据此宣称动作达到商业游戏质量、长时间稳定帧率或完整寻路能力。

最终追击复验：守井者实际离开出生点超过1.8米，真实游戏随后进入胜利状态。修正了运动胶囊与地面的初始接触；可见脚底位置不变。供电交互、锁定、攻击、短闪及暂停已在手动窗口产生响应。
