## 本版提出的固定细节

- 肩甲位于角色解剖学左侧：正面图观者右侧，背面图观者左侧；右肩为软布。
- 深灰开衩斗篷，前领中央圆形旧金属扣；背部呈折叠兜帽形态，这是本次图像中的新增候选细节。
- 旧皮革斜背带、腰带、前臂护具与手套；深色内袍、长裤和皮靴。腰带采用图中的主带与细辅助带组合。
- 一把长剑斜背：剑柄在角色右肩上方，鞘尖向左臀下方延伸。此处仅确定静止携带外观，不代表长剑拔出动画或背带结构已验证。
- 第一章不配固定井灯、工具背包或第二把武器。不依据本图扩展换装系统。

## 已做的视觉检查与限制

已查看生成结果：三个视角的黑发、成年人体比例、左肩甲、剑柄侧别、手套与靴子整体可对应；全身与脚部未裁切；无海报手机和商城 UI 混入。

确认此版外观后，再以同一参考图生成连续场景视角；正脸、扣具和肩甲不得在每个镜头随意重新设计。
