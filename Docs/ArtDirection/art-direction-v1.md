# AshWell / 灰烬深井 · 整体美术规范 v1.2

日期：2026-09-10。v1.2 根据本轮确认保留少量工业感，明确为古代机关；延续 v1.1 的古老奇幻主体。文件名保留以保持已有链接有效。

## 一句话定位

**具有魂系气质的古老奇幻冒险：一个披着旧斗篷的无名旅人，穿行于沿深渊层层展开的城池、断桥与地下圣堂，在壮美、危险与寂静交替的世界中逐步下行。**

关键词：壮美、古老、神秘、衰败、探索。写实材质与绘画式构图结合，危险与宁静交替，开阔视野与封闭遗迹形成节奏。

《艾尔登法环》是用户指定的气质与体验参考：目标是宏大遗迹、远景吸引、谨慎探索和有重量的战斗。建筑、角色、符号与故事采用 AshWell 自己的设计。当前制作目标仍是一段包含探索、捷径、敌人与 Boss 的完整区域，不据此扩展为完整开放世界。

## 定稿范围与依据

- 本文件作为后续环境、主角、敌人、光照、特效与 UI 的共同美术基准。早期视觉文档保留为历史记录；与本文件冲突的美术选择以后者为准。
- [用户海报原图](References/ash-well-poster-2026-09-10.png)用于气氛、人物轮廓和空间层次参考。手机外框、商店界面、蓝色 Get 按钮与英文营销文案不是游戏设计要求；巨大日轮也不是新增天体设定。
- 保留[第一章既定路线](../Concepts/Chapter01/README.md)的通行顺序和已有玩法作为实施基线；其工业主导的视觉目标已被本规范取代。后续场景以古城、拱廊、悬桥和地下圣堂建立主体，机械退到有明确用途的局部地点。美术调整不自动改写任务和剧情。
- 最新故事候选为[《未竟之日》剧本 v0.3](../Story/ash-well-screenplay-v03.md)。旧工业故事与姐姐救援线保留为历史提案；本文件不自动确认新剧本的时间规则、王国历史或人物关系。
- 这是制作目标，不代表现有 UE 资产已替换或当前实机已达到海报质量。

## 1. 画面风格

采用自然人体比例、可信的布料石材金属和有重量的建筑。构图、明暗与色彩做明确取舍：大形先于碎细节，轮廓先于纹样，焦点先于满屏精度。

风格位于写实与绘画感之间：不使用卡通描边、夸张大头、塑料般光滑表面，也不以满屏扫描噪点追求写实。远景可简化，近景的接触、磨损和材质反应要可信。

核心观感是“壮美、神秘而值得探索”。允许明亮天空、自然植被与温暖遗迹出现；永夜和全域地下封闭不再作为美术硬约束。具体新增地表场景仍须另行设计。黑暗用于节奏与未知，不通过持续压黑整屏制造气氛。

## 2. 色彩与光照

下列色值为概念与界面参考色，不直接作为 PBR 材质物理参数或灯光数值。

| 色系 | 参考色 | 用途 |
|---|---|---|
| 炭灰 | #252B30 | 主角斗篷、深部结构、界面底色 |
| 雾蓝灰 | #74838C | 空气透视、环境冷光、远景 |
| 风化石灰 | #8B8980 | 主体建筑与岩石的中间调 |
| 旧铁褐 | #544C42 | 机械、支架、金属磨损 |
| 灯火琥珀 | #D5A25C | 火光、居所与局部视觉引导 |
| 晨光米白 | #E7D7B8 | 天光、出口、关键开阔时刻 |
| 暗苔绿 | #535C46 | 潮湿边缘与少量恢复中的自然 |

冷灰石色是基础，旧金、苔绿与暖光形成区域变化，不把所有地点统一成蓝灰加橙灯。琥珀光可来自火焰、居所或设施，不单凭颜色保证安全；交互必须另有形状或文字提示。

室外以云层漫射光和低角度暖光形成层次；深井的光来自井口、竖向开口、灯具与设施，不能无来源地照成日落峡谷。开阔处保留海报的明亮远端，地下用远处灯群或被照亮的结构实现同样的吸引力。

雾服务纵深：近处清楚、中景分层、远景收敛。人物深色衣料仍保留褶皱与轮廓；战斗前摇、地面落差和道路边缘不能被雾或曝光吞没。

## 3. 世界与建筑

统一语言为“沿深渊层层展开的古老奇幻城池”。城堡、断桥、地下圣堂、陵寝与风化遗迹主导大轮廓。厚重基座、竖向塔体、多层拱廊和桥梁建立历史与尺度。升降机、拉索与旧机械只出现在通行或任务需要的位置，作为古文明遗留，不再让管道和检修平台主导全域。

本轮明确保留：石厅绞盘、升降笼、巨链、配重和束缚装置。远看是古城与深渊，近看才读到古代机关；不以现代电控面板、流水线和密集服务管线塑造全城。驱动力可以是人力、配重或待剧本确认的古代力量。

建筑优先使用竖向节奏、深窗洞和克制的尖拱或圆拱。机械沿承重、供能和通行关系布置，不用无用途的齿轮、管线和尖塔填满画面。

每个主要视点应具备近景立足点、中景可读路径、远景地标。先让玩家看到想去的地点，再用转折、下降和遮挡逐步接近。远景体量可以不可达，但不得伪装成可交互入口误导路线。

损坏有原因：承重失效造成坍塌，渗水造成污迹，持续使用造成磨亮。生活区出现修补布料、门灯、晾晒与工作痕迹；全世界不能都长成无人墓地。

第一章美术迁移目标：配给街以旧城街巷与暖窗表现生活；矿道保留狭窄节奏；栈桥展现深渊古城；检修站用古老石厅包容必要设备并保留清晰战斗空地；升降机以更深处的遗迹轮廓和零星灯火延续探索欲。此处是待实施目标，现有地图并未因此完成重建。

## 4. 主角

视觉评审稿：[固定服装正侧背三视图 v0.1](Characters/hero-turnaround-v01.md)。本图将肩甲侧别、扣法与剑鞘位置具体化；脸部及新增细节仍待评审，不代表模型已完成。

确定采用海报中的年轻男性旅人方向：自然成年人体比例、深色短发、轻装、深灰斗篷、单侧旧肩甲与一把朴素长剑。体形灵活结实，避免宽肩重甲遮住动作。

背面识别点：**不对称旧肩甲、开衩斗篷、朴素长剑。** 第一印象是无名旅人，服装以磨损、修补和实用穿戴表现经历。井灯和工具降为可选装备，不作为固定身份标记，不以检修工职业约束主角外形。

斗篷到膝部附近，后摆开衩，站立保持海报的垂坠感，运动时能露出腿和武器。长剑入鞘时斜背，战斗时明确持于手中；装具位置须与拔剑动画匹配。衣物为炭灰、煤褐和旧皮革色，避免纯黑一整块。

正脸以自然、略显疲惫、可信的年轻成年人为基调。精确五官、发型分束、纹样和三视图留在角色设定阶段收敛，不从单张背影假定已经定完。暂不增加发光眼睛、王族徽章或具有剧情含义的伤疤。

## 5. 敌人与居民

现有守井者保留为局部古代装置题材的 Boss，维持已有战斗与“人被困在装置中”的叙事线索；它不再定义全游戏敌人的美术语言。后续新增敌人先按所属遗迹、职责与体态建立原创轮廓，允许旧甲守卫与奇幻生物方向，但本规范不新增具体敌种或制作清单。守井者外形整合优先减少现代设备观感，以旧铁、封闭护甲与有重量的结构融入石厅。

敌人与主角靠体量、轮廓和动作节奏区分；暖色供能不等于友方。攻击提示可使用受控的锈红或橙红，但必须配合姿势、声音和形状。

居民与主角共享粗布、皮革、旧铁的材料体系，通过岗位用品、修补习惯与穿戴方式体现差异。现有 Boss 无需因海报而重新设计全套模型，后续先校准材质和照明是否融入新标准。

## 6. 材质、动作与特效

- 石材：有大块结构和边缘磨损；潮湿集中于合理区域，避免全场油亮。
- 金属：深色旧铁为主，接触处露出金属亮面；锈蚀有分布依据，不把所有表面刷成橙色。
- 布料与皮革：粗糙、厚薄有别，褶皱服从运动与绑扎；破损集中在容易磨损的位置。
- 自然：苔藓与低矮植被局部出现，服从光照和水源；灰烬是局部空气细节，不遮盖整屏。
- 动作：行走、转身和攻击有重量但响应清楚；披风、装备与镜头的晃动不能干扰战斗判读。
- 特效：火星、灰尘、蒸汽、碎屑和短促冲击为主。避免常驻光翼、霓虹描边与大面积彩色剑气；命中清晰度高于粒子数量。

## 7. 镜头与界面

以第三人称背后视角为主。常规移动看得清脚下与下一段路径，战斗能同时读到人物、敌人和躲避空间。宏观视点允许角色显小，但不强制把海报的静态站位套到全部玩法镜头。

UI 使用炭灰半透明底、米白正文、少量旧金或琥珀强调。标题可用克制的衬线字体，正文与数值优先清晰易读。边框纤细，装饰有限，默认露出足够世界画面。

正常游玩仅显示当前必要状态与交互提示；不得把 App Store 的手机外框、底部商城导航和 Get 按钮纳入游戏 HUD。危险、选中和可交互状态不能仅依靠颜色区分。

## 8. 制作验收

在 UE 实际游玩镜头中检查，而非仅用概念图或宣传镜头判断完成：

1. 缩小画面后仍能识别主角、主要路径与一个视觉焦点。
2. 主角站在暗石、雾景与暖灯前，肩甲、斗篷和长剑均能形成稳定轮廓；不依赖发光装备才能辨认。
3. 近中远至少三层可辨；雾与曝光不吞掉攻击前摇、台阶和边缘。
4. 石、铁、布在同一光照下能看出区别，表面噪声不抢主体。
5. 第一眼能读出古老奇幻遗迹，机械只在有用途的局部出现；建筑支撑、路线和设施位置连贯。
6. 开阔处让人想继续走，生活处能感到有人存在；压迫不是全程相同的亮度和情绪。
7. 实际跑动、拔剑、攻击、闪避时，斗篷和装具不明显穿模或遮挡判读。

下一项可评审产物是主角正侧背设定与同场景 UE 游玩视角对照。先验证轮廓、构图和灯光，再投入微小纹样与高精度表面。不得将本文件视为扩大关卡、重新打包或全面替换资产的执行指令。
