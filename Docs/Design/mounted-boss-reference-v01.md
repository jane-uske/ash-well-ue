# 骑乘 Boss 战斗实验：参考拆解与设计初值 v01

日期：2026-09-10。范围：AshWell UE5 的独立室外骑乘 Boss 实验。本文负责参考证据与设计建议；不代表代码已经实现或 UE 验收通过。

## 判断

复用现有步战角色、操作与死亡重试是合理的。真正新增的成本是马的运动、骑手同步、长兵器路径、可读的追击与快速目标镜头。只列五个攻击动画会低估这部分工作；五招必须连同运动与恢复状态一起交付。

将大树守卫作为动作与空间关系参考是合理的；第一版不应逐项复制原作。原作视频里的玩家装备、血量、伤害、镜头与场地并不等于 AshWell 的可用初值。以下设计值用于本项目实验，最终以当前代码和实际游戏窗口为准。

所有时长从本招开始计时，单位为秒；位移单位为厘米。距离先定义为 Boss 中心到玩家中心的水平距离，最终必须按实际马体尺寸重调。这里列的是建议而非已经落地的程序常量。

| 招式 | 使用条件初值 | 前摇和停止修正朝向 | 可见路径及位移 | 有效伤害窗口初值 | 恢复和反击机会 | 初始冷却 |
|---|---|---|---|---|---|---|
| A 右侧横扫 | 近身 170–410 cm，前方或右侧；非后背 | 前摇 0.75；t=0.50 锁住出手朝向，之后只播放姿势，不跟着玩家扭整匹马 | 骑手右肩后拉，刀头向右外侧→前方→前左，腰胸高度下降到玩家上躯；马小步前进 30–70 cm，避免原地转盘 | t=0.75–1.05；沿可见刀头及刃段做连续扫掠，一次攻击对同一目标只伤一次 | 结束后 0.75；若已承诺连招，则改为可读的举戟姿势连接 B，不能把停顿伪装成完全恢复 | 2.6 |

| C 冲锋掠斩 | 550–1300 cm，前方约 ±35°，前进通道有足够净空 | 前摇 1.15；t=0.90 锁住冲锋轴；锁定后直线/固定缓弧，不再追玩家位置 | 前腿起步、骑手压低，马加速到约 900 cm/s，经过玩家身侧；高速段最长 1.15 秒；出手刀头扫过侧前方；越过后制动并宽弧回转 | 武器只在高速段的指定挥击子区间激活；冲锋身体若开启伤害须用单独碰撞源和单次命中 ID；同一次穿越不能连续吃马身+刀两次满伤 | 最少 1.20；先制动，速度降到约 200 cm/s 以下才大转向。玩家侧向闪避后能追打，代价是需追回距离 | 6.0 |

D 与 E 是为第一轮资产成本和可读性做的简化，不应标成“原作盾撞/马蹄招式已准确还原”。若现有资产更适合盾砸地，可用同一状态与窗口改为盾落地；不要为了名称临时添一个缺乏配套动作的招式。

### 连招与阶段

- 第一阶段先掌握 A/B/C/D；第二阶段只引入 E 与一次有限 A→B 连段。阶段建议 55% HP，过渡只做一次 1.4–1.8 秒无伤害整理，不用突然把全招加速。
- 决策在状态边界执行，依据距离、相对角、冷却、场地净空和上一招。规则筛选后才允许小幅权重变化。不能每帧重选，也不能随机换动画掩盖没有决策。
- A→B 是否连招应在 A 开始或最迟 A 的有效窗口之前明确承诺，保留明显高举后续姿势。B 完成后保证恢复；不使用无限追加。
- 在玩家身后/极侧面时先移动整理位置，不能把横扫的攻击朝向瞬间翻转 180°。冲锋后最多进行普通低速回转，不立刻再冲锋。
- 普通追踪的转向上限应随速度降低：步行约 100–125°/s，中速约 55–75°/s，高速约 25–35°/s。用速度/角速度计算实际转弯半径并在记录中检验。

## 判定、玩家规则、镜头与声音的验收约束

1. 身体阻挡、武器伤害、盾伤害和落地范围使用独立来源。默认马身只阻挡；仅明确的冲锋状态才可启用身体伤害。每次出招有唯一攻击 ID，单个目标不被同一窗口每帧重复伤害。
2. 高速刀头使用上一帧至当前帧的扫掠，至少检查刃端和刃段；不能只用 Boss 到玩家的圆形距离。调试视图同时画可见刀头、有效扫掠、伤害事件和朝向锁定标记。
3. 容错从可见刃缘向外小幅增加，例如 12–18 cm；若需要膨胀到半匹马大小才能打中，应先修路径/距离/时序。让 UI 与命中日志告诉玩家被哪种攻击击中。
4. 本轮应重新量当前主角轻击、重击、闪避与恢复。可试轻击 8–12、重击 24–30、闪避 20–24 体力的独立场景配置；不要无证据全局修改守井者基线。体力参数以当前最大值和实际恢复速度换算后决定。
5. 输入缓冲建议 0.15–0.20 秒，只有一项待执行动作；过期丢弃。轻击允许前摇早段取消或后摇尾段取消，出手有效段保持承诺；重击早段可取消，后段不可取消。取消必须保证没有重复扣体力/重复命中。
6. 闪避无敌先用现有实测窗口；若调参，可试闪避开始后 0.06–0.32 秒。必须分别测窗口前、内、后三次碰撞；只观察翻滚姿势不等于确认无敌。硬直、死亡、空中规则不能被缓冲绕过。
7. 镜头锁定目标建议位于鞍座/马胸与骑手躯干之间的稳定点；不跟马头/武器尖每次抬高。竖向跟随限速，近身适当拉远，冲锋方向变化有最大角速度；以玩家、武器侧和马体同时可见为准。
8. 不用每次命中慢动作。轻击短音效/小幅材质响应，重击可用 30–45 ms 停顿实验但要单独测输入与帧率；震屏小而短。范围攻击用落点与落地音强调，避免浓尘挡住下一招。
9. 马蹄声来自实际足落地事件/相位；武器风声来自有效挥速；命中声来自碰撞成功；落地重音来自落地。不得播放了挥刀动画就提前播放命中声。

## 如何作出通过/失败判断

| 验证 | 有效证据 | 不算通过 |
|---|---|---|
| 马步与转向 | 侧面近距录像：直行、变速、左右弯、停止；支撑蹄相对地面稳定，半径符合速度 | 已有腿部动画、移动数值正确、截一张站立图 |
| 骑手同步 | 五招各至少一段近距游戏录像；骨盆/鞍座、手/武器和脚/马体无明显脱离 | 绑定成功、UE 资产存在 |
| 可读/可躲 | 同一招先故意受击、再按读招闪避、再利用恢复反击；位置与日志对应 | 只让自动脚本无伤/只把 Boss 血扣到零 |
| 朝向锁定 | 玩家在锁定时刻前后分别横移，攻击后段朝向不再追随；记录锁定 yaw 和实际 yaw | 文档写了“无追踪” |
| 碰撞来源 | 马身贴靠不掉血，武器/盾/范围各独立命中与躲过；一次攻击无重复伤害 | 统一半径碰撞碰巧能打中 |
| 镜头 | 正面、两侧、马腹近距、冲锋擦身、场边各有实录 | Boss 远处静止时看得清 |
| 完整循环 | 原生 UE 窗口完成入战、脱战、再入战、玩家死亡→R、胜利→R；状态和血量归零重建正确 | 只编译通过或只有进入地图截图 |
