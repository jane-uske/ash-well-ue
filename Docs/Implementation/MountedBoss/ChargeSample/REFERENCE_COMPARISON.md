## 优先级

1. 盾牌：当前 180 cm 是为匹配旧碰撞表现沿用的尺寸，不能替代美术比例判断。原片可观察盾/骑士比例，但不可从透视图反推精确米数。先准备较小尺寸候选，复核装饰面、把手/前臂和骑手左侧轮廓。
2. 马匹低速与制动：当前全局 StrideRate 下限和 Idle–Walk 混合会同时影响步幅与频率，应在 UE BlendSpace 的实际样本速率上逐项校准；不能只改变 Actor 速度掩盖滑步。
3. 人马重心：沿独立骨架和现有 Slot / Montage 路线，检查鞍座、脚蹬、骨盆到胸肩的分层回正；不合并骨架。
4. 可读性：只调当前庭院的填充光、雾/远地表和固定曝光相关参数，保存碰撞前后清单作一致性检查。尚未执行大地形或背景制作。
