## 录制核查已确认

旧 B：原始墙钟 18.023722 秒、324 张采集帧；封装视频 18.000 秒、324 帧；原始 WAV 为 584704 个采样帧 / 48000 Hz = 12.181333 秒，封装 AAC 为 12.181 秒。音频在封装之前已短约 5.84 秒。旧音频不可用变速、静音填充或插帧修复为合格实录。

原始采集目标 24 fps、有效采集约 17.976 fps；最大采集间隙 149 ms。ffconcat 默认输入时基还把原始时间戳量化到了 40 ms 网格。组装器现增加音频时长拒收门槛，并使用毫秒输入时基。录像帧率不能直接当 UE 运行帧率。

同次 Debug 日志的 record_start / record_stop 游戏全局帧号由 338 到 1278，墙钟间隔 18.109 秒，约 51.9 次游戏帧推进/秒；不是 GPU 呈现帧率、不是稳定性承诺，也不能移用到清理后的性能结论。

源码定位：AudioMixerSubmix.cpp 的静音自动停用路径在录音采样追加之前提前返回。UE 自带 au.NeverDisableSubmixes 可让静音时段继续处理；同段验证已通过时长门槛：墙钟 18.031460 秒，WAV 18.026667 秒，差约 4.8 ms；356 张采集帧的封装时间误差最大约 0.505 ms（旧版约 52.6 ms）。这不是全部音画事件同步验收，也不是 UE 性能达标。只验证 WAV 文件完整的旧门槛不足，已补充音频覆盖时长检查。现有原件与旧录像保留不覆盖。
