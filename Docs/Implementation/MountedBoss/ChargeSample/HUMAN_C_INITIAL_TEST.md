## 开始

双击项目 Scripts/launch_mounted_human_test.command。游戏启动后，QuickRecorder 选择 Window → AshWell；选择 60 FPS，开启 App's Audio，关闭 Microphone，开始录制。不使用游戏 F8 的逐帧 PNG 导出。本次使用现有真实窗口录制，R 重试和载入画面都应连续保留。

正式按键：WASD 移动；鼠标看向；E 入战；Tab 锁定；空格跳跃；Shift 短按闪避、长按冲刺；鼠标左键轻击、右键重击；R 重试；Ctrl 慢走。

正常试玩 10–15 分钟。可以自然尝试接近、锁定、闪避、追击反打、死亡后 R 重试，不必刻意表演特定招式或满足测试指标。不用数字选招和 F1–F8 调试键，不改 Boss 血量和 AI。

## 结束

正常退出本次游戏窗口可使 QuickRecorder 完成窗口录像并返回主界面；也可先手动停止录像再退出。告诉我录像位置以及最明显的 1–3 个感受即可：例如读不清、盾挡视线、冲过去后难追、脚滑或输入别扭。不要为了凑时长持续玩有严重不适或无法操作的版本。

日志自动保存到 Saved/MountedHumanTests/日期时间/，包括启动参数、模块 hash、引擎日志和跨 R 重试的输入/状态/接触时间线。窗口录像默认在 QuickRecorder 配置的桌面目录；录完再归档到对应初测会话，保留原件。
