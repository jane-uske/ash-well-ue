# Mounted Boss 战斗规格

版本：六招源代码审计，2026-09-11；UI 修复前同一构建 27/27 自动化用例通过；真实 UI 随后发现 F1–F8 引擎绑定冲突和同帧暂停推进，当前修复真实 UI 日志 13/13 通过，后续录制改造的必要战斗回测 9/9 通过，视觉与人工交锋验收仍未完成。**以下参数属于 AshWell 实验，不是《艾尔登法环》原作数值。** 源文件 hash 随 `move_catalog.json` 记录，实际测试和视觉验收分别标记。完整动作覆盖索引见 `move_catalog.json`，运行证据见 `qa_matrix.json`。

## 坐标、职责与状态

- UE 单位为厘米，时间为秒。Boss 原点为马在地面的中心，局部 +X 向前、+Y 为右、+Z 向上；左右统一按 Boss 自身。
- 玩家复用 `AAshWellCombatCharacter`，骑乘场景通过 `MountedCourtyard` 关卡名走独立分支；Boss 为独立 `AAshWellMountedBoss`。旧 `AAshWellWarden` 和 `AAshWellCombatArena` 保持原路径。
- Boss 状态为 `Idle → Approach → Windup → Active → Recovery`；可转 `PhaseChange`、`Return`、`Dead`。选择招式只在合适状态边界发生，姿势计算不自行决定下一招。
- 战斗移动使用代码加减速与连续碰撞，马循环按实际移动距离推进，骑手跟马胸背骨架；当前不是全 Root Motion 方案。Root Motion 可作为后续独立动作位移适配，但必须保持同一攻击时钟和明确责任。

## 运动、转向与马步

当前普通加速度 380 cm/s²、制动 700；冲锋 Active 加速度 1300，马肩撞 1000。Approach 随距离使用约 145/260/400 cm/s，近身正面对齐后停步。转向半径计算 `260+Speed×0.50`，角速度 `degrees(max(Speed,130)/Radius)` 限制在 27–72°/s；转之前用马体箱检测新角度是否重叠阻挡。

`MoveSwept` 在地面方向先做马体箱扫掠，边界保留 185 cm 余量，再更新实际行进距离。马步跟随**实际走过的距离**，被挡住不会只因期望速度高就继续奔跑。Walk 参考速率为 114.13 cm/s；Gallop 当前通过 `MountedGallopDistance.inl` 的相位—距离表反解相位，源码中 477.34 的旧平均值不再决定其每帧推进。转弯按半径 65 cm 的角行程补充可见踏步。

这还不是足底锁定系统。马无专门转弯/停止片段；转弯通过循环踏步、相位与整体有限转向组合，扬蹄为程序旋转。已记录支撑足漂移，因此“有骨架”“相位按距离”不能作为不滑步验收。

## Boss 选招、阶段与反击机会

当前选择器依次检查以下条件，均须对应冷却结束，范围为严格大于/小于：

| 优先次序 | 招式 | 条件 |
|---|---|---|
| 1 | 跃盾 | P2，320<距离<600 cm，绝对角<30° |
| 2 | 蹄击 | 距离<340 cm，且 P2 或绝对角>100°；后者用于回应贴马尾行为 |
| 3 | 马肩撞 | 距离<215 cm，绝对角<55° |
| 4 | 冲锋 | 570<距离<900 cm，绝对角<20° |
| 5 | 下劈 | 距离<310 cm，绝对角<50°，选择序号为奇数 |
| 6 | 横扫 | 距离<315 cm，相对角在 -40° 至 +110° |

没有可用招式时再等 0.12 秒，并继续有限转向/接近。自然脚本战曾暴露贴马尾无招可出的漏洞，增加蹄击后方触发是本轮适配；这不证明原作有同样的 AI 条件。蹄击范围仍以前方 85 cm 为中心，选择范围内的每个后方位置并非都能命中，需要继续用自然交锋核验。

- 900 HP；≤450 HP 设置待进入阶段。已有攻击先完成 Recovery；若位于 Approach，则直接进入 1.65 秒无伤害的 PhaseChange，随后 0.40 秒决策延迟。玩家可以在该恢复阶段攻击。
- P2 横扫且选择序号模 3 为 0 时，允许在完整横扫 Recovery 后、目标距离<470 cm 接一次下劈；这是最多一次的条件连招，下劈仍有完整前摇和恢复。其余动作结束后给 0.28 秒决策延迟。

- 不以“玩家正在治疗/按下按钮”作为现有已实现事实。魔法检测、盾反射、输入读取均没有本轮运行证据。
- 提示朝向何时锁定，窗口关闭后伤害必须停；恢复时可被玩家攻击，Boss 普攻受击不打断攻击承诺。当前无独立姿态条或处决，不把短反应叫成完整姿态系统。

## 碰撞、武器、攻击时钟

马身用于物理阻挡，指定马肩撞期间同一马身扫掠也可产生伤害；长戟与范围分别处理。当前真实马体半长 108、半宽 43、半高 80 cm，玩家胶囊半径 34。它不是全马轮廓的精确逐三角形碰撞，且当前马身忽略 `ECC_Camera`，所以必须人工检验近身镜头穿模。

长戟轨迹由解出的右手握点与同一方向生成。除了杆刃远端 7 点连续扫掠，还加入可见宽刃边缘样本；扫掠半径 18 cm。进入新的有效姿势后重置上一帧采样，避免把前摇到有效段的姿势跳变当成跨场伤害。

Boss 战斗内部最多按 120 Hz 分步，视觉马骨架每渲染帧评估，之后刷新骑手座位和手部姿势。**多次逻辑子步不自动等于多帧视觉动画**；最终需比较运行录像、调试刃缘、接触事件和 actual damage。

每次有效接触只消费一次事件，即使 ApplyDamage 因无敌返回 0，也不在下一帧重打同一招。D/F 已使用同一消费标记；`ReceiveMeleeHit` 还记录玩家攻击 ID 防重复。普通贴身没有持续马体伤害。LeapShield 当前实现是“根落地＋盾底门限”开启**一个**范围源，没有独立盾牌接触扫掠，因此不存在两个伤害源叠加，但也不能写成精确盾面物理碰撞已完成。盾底门限是盾中心 Z 减半高的代理值，仍须结合画面验证。

## 镜头、音效与反馈

锁定点为 Boss 地面中心上方 185 cm 的稳定点。锁定横向追随上限 105°/s，俯角目标 -10°，长臂随距离为 650–800 cm，未锁定 540；FOV 80/76。镜头 offset.Z 直接赋值避免被父类 102 cm 的走路偏移反复覆盖；锁定冲刺不强扭人物朝向。

普通命中不使用全局慢动作；旧正常 fixtures 最小 time dilation 均为 1。命中 Burst 和震屏降低，音频分别由挥动、成功接触、落地、实际马蹄下降接地触发。现阶段音色仍是复用资产，听感未验收。

Debug 已实现：F1 面板、F2 暂停/恢复、F3 0.25×/1×、F4 战斗快速复位、F5 恢复自然 AI、数字 1–6 放置对应测试位置并执行一次指定招式；再次按数字重来。不是自动无限循环。

F4/F5 有意保留当前速度供同速对比；要恢复正常实战速度需按 F3 并确认面板显示 1×。F4/F5 会解除暂停、清理当前攻击；离开场景还原由 Debug 设置的慢速。调试面板显示状态、动作时间、伤害窗口、锁向、玩家无敌、体力与实际马速，事件日志是追溯记录，**不是确定性逐帧回放**。

F8 当前通过 FFrameGrabber 抓取呈现的 UE 视口并录主混音，目标 1280×720 / 24 fps；PNG 在线程池编码，最多八个在途/排队写入，落后时记录真实时间缺口。逐帧保留请求与读回时间戳，不补造流畅帧。早期 12 fps 截图录制方式已替换；当前输出完整性、音画时序及能否交付仍须检查实际文件。F8 停止或任意 Actor EndPlay 都关闭本段、撤掉录制 ticker、等待已请求帧/音频保存；R 重载结束一段，重载后再次 F8 开新段，不把加载空白剪掉伪装成连续跨场景录像。

正常 QA 与实战录像必须标清慢速/单招模式，不能以调试 0.25× 得出正常速度可读性结论。

## 入战、脱战、死亡和胜利

玩家从西侧入口开始；E 可进入挑战，进入场地且达到感知距离也会入战。退回西侧阈值 x<-1750 或长距离离开超过约 2 秒触发 Return，关闭攻击，返回原点、停下并回到初始朝向后重置；玩家恢复生命/体力。Return/Dead/Idle 通过统一清理关闭伤害、连招、武器历史、活跃音效和局部 VFX。若退出 Active 时根位置仍离地，则按 550 cm/s 持续下降；DebugCancel 快速复位直接落地是调试特例。

玩家死亡关闭移动/锁定，Boss 应收手；R 通过同关卡 OpenLevel 创建新实例，重置攻击消费标记、阶段、速度、朝向、血量、动画相位与 Debug 控制；最终 retry fixture 已证明新实例 100/900 生命、Idle、未入战。Boss 死亡立即终止伤害和实体阻挡，胜利反馈后允许 R 再试。UI 提示不是这些条件已通过的证明。
