# 普通大树守卫：招式与打击反馈核查

日期：2026-09-12。用户最新决定：停止精修和继续放大，先调研原作招式及当前碰撞、挥剑、砍击、音效缺口。本页覆盖宁姆格福持戟盾的大树守卫，不混入龙装守卫、火把变体或黑夜君临。

## “官方几招”的证据边界

本次未查到可核实的官方完整招式总数或官方动画ID表。不能把我们已有的六个程序入口说成原作全部招式。

[Game8](https://game8.co/games/Elden-Ring/archives/353499)列出八个攻击类别；[GameSkinny](https://www.gameskinny.com/tips/elden-ring-boss-guide-how-to-beat-tree-sentinel/)用七个标题整理攻击，并把部分连击合并描述。[EIP](https://eip.gg/elden-ring/guides/how-to-beat-the-tree-sentinel-boss/)另外明确列出转身接回扫。它们是攻略作者的分类，覆盖也不完全一致，不是官方“总共八招”或“七招”的证明。

下表以Game8八类作为索引，名称为描述性译名；对应关系是本工程审计判断，不表示动画等价。

| 原作攻击类别 | 当前对应 | 缺口 |
|---|---|---|
| 近身戟横斩 | `sweep`旧实现 | 未完成反手、连段分支与参考动作对应 |
| 正面戟突刺 | 无 | 缺独立动作和判定 |
| 跃步／过顶戟砸击 | `overhead`旧实现 | 仅粗略对应，不能将不同起手全部算已还原 |
| 冲锋挥戟 | `charge` | 当前唯一集中精修样本，体量和重量仍被用户否定 |
| 盾牌魔法反击 | 无 | 缺反制行为、动作、投射物及反馈 |
| 跃起范围砸地 | `leap_shield`旧实现 | 只覆盖一个盾砸原型，其他变化未覆盖 |
| 追身盾击及地面变化 | 无独立入口 | 不能与一次跳盾砸合并后称完整 |
| 前蹄践踏 | `rear`旧实现 | 必须继续区分纯踩踏与扬蹄接戟击 |

八类之外应另登记核准：上挑（GameSkinny）、转身接反手回扫（EIP）、近身盾推与马体侧撞（GameSkinny的Shove分类）。当前`body_check`对应马肩撞原型，不代表盾推也已完成。不能为了凑数量将起手、挥击、恢复各算一招，也不能把多个需要不同应对的连段变化全部算成一个已完成动作。

## 当前不是“只有一个入口”，也不是“六招成品”

源码`AAshWellMountedBoss::SelectAttack`仍包含横扫、重劈、冲锋、马肩撞、扬蹄、跳盾砸。五个旧动作是兼容实现，只有冲锋接入本轮成套人马Montage流程；六个程序分支不能证明自然交锋具有原作丰富度。

已展示的B录像是显式冲锋检查，开头强制这一招，之后恢复AI；玩家站立，没有展示真人挥剑、贴身周旋和反打。它只能证明专项演示，不能用来宣称完整Boss实战成立。当前冲锋后拉远、站位和选招条件也会使演示反复落入冲锋，真实近身招式分布尚需普通输入记录。

## 碰撞和声音：哪些有，哪些没有做好

| 项目 | 已有证据 | 当前判断 |
|---|---|---|
| 马体阻挡 | 原生Box碰撞、移动Sweep与身体接近测试 | 有碰撞，不等于身体压迫、挤压和受力表现做好 |
| 戟命中玩家 | 可见兵器路径Sweep、扣血、闪避窗口 | 有判定；比例曾引发下坡漏击，不能称天然可靠 |
| 玩家剑命中Boss | 剑轨迹Sweep、`ReceiveMeleeHit`扣血与去重 | 有规则，现有B未演示玩家进攻 |
| 挥剑/挥戟声 | `AW_Battle_Swing`等基础合成素材及播放调用 | 有接线；正式兵器风声层次和动作点同步未完成 |
| 砍击铠甲 | 玩家命中调用`MetalHit`，Boss命中复用`GroundSlam` | 通用合成素材，不是材质/命中部位区分的成品声音 |
| 盾挡反馈 | 当前盾组件无独立碰撞；剑击目标是Boss马体Box | 缺真正盾挡判定与配套金属反弹反馈 |
| 骑士受击表现 | 有`HitReaction`变量，旧姿态路径可消费；新骑士没有专门受击Montage/破韧流程 | 扣血不等于新骑士可读的受击反馈；也不该每刀打断重甲Boss |
| 火花/冲击 | 有通用Burst及小幅镜头反应 | 未按铠甲、盾牌、身体、地面做成熟接触反馈 |

可定位的错位：`ChangeState(Active)`播放Boss挥击声，冲锋的Active从Launch=0.90秒开始；真正武器窗口Strike=1.48秒，代码接法使挥击声比标记早约0.58秒。修正应跟随动作Notify及实际命中事件，不应靠增加整体音量或扩大隐形判定掩盖。

`Native-charge-192959/window-uncut.mp4`不是全静音，整段音轨平均约-46.2dBFS、峰值-17.5dBFS；含等待，不能把平均值当作每次打击音量。该片无玩家挥剑输入，声音非零也不能证明挥剑/金属命中/盾挡都正确。声卡日志另有采样率查询警告，尚无证据证明它是用户听感问题根因，不归咎于用户设置。

源码核查点：`AshWellMountedBoss.cpp`的`ChangeState`、`TryDamage`、`ReceiveMeleeHit`；`AshWellCombatCharacter.cpp`的剑轨迹、命中与受伤处理；`AshWellMountedSampleRig.cpp`组件碰撞配置。素材来源见`SourceAssets/BattlePolish/audio-manifest.json`，明确为确定性合成素材。
