通过 Meshy 插件查询、下载并记录来源，Blender MCP 做骨架与姿态检查，UE MCP 导入独立试验资产。执行前确认两端连接与当前工程；不改其他 Blender 文件或 UE 项目。

优先筛选：

| 用途 | Meshy 候选 | 要检查的内容 |
|---|---|---|
| Boss 重砸 | 127 Charged Ground Slam、128 Heavy Hammer Swing | 持握手、屈膝承重、上举和恢复；双手动作不能直接冒充单手 |
| Boss 近身踹击 | 103 Simple Kick、206 Spartan Kick | 支撑腿、重心、前方范围，能否适合重装体型 |

每类最多先取两个候选；不合适才用文字生成补位。下载后保存到项目 `meshy_output/`，保留任务 ID、真实积分消耗、格式、授权信息。

Meshy 动作作为源动作；Blender 负责重定向到现有玩家骨架及守井者装甲骨架，修握持、手足接触、根位移和权重。UE 战斗状态仍负责位移、伤害与动作阶段。源动作不适配时退回已有动画，不能为套动作换掉已确认外观。

交付：相同机位的现有版/候选版比较；至少一条玩家动作与一条 Boss 动作在实际角色上完整播放，而非仅在标准人形上预览。

## 第二步：穿模、闪避和声音先成立

- 校准玩家/Boss 胶囊、移动停止距离、攻击有效距离及动画最大身体位移。移动、闪避与突进使用扫掠并正确处理阻挡，不能穿过对方躯干或场地围栏。
- 用稳定的身体分离与受阻滑动处理贴身情况，避免每帧瞬移推开或抖动。身体碰撞与伤害检测分开。
- 肩肘、锤柄与身体的自相交通过姿态、权重和握持修正处理；不能靠无限放大碰撞体遮掩。
- 换成有预备、压低重心和收势的紧凑翻滚，匹配实际闪避方向。保持当前体力 28、0.5833 秒总时长、0.07–0.37 秒无敌窗口作为首轮基线；动画不合适则采用低身跨步，不强行压缩成长时间空翻。
- 位移仅由一处控制，去除动画重复根位移。足底接触与站立恢复做本地修正，动画衔接保留短混合。
- 先让挥空、玩家命中、玩家受击、闪避、Boss 起手和落地声音在正常音乐音量下可辨识。补衣料/装甲摩擦与落脚层。Suno 负责配乐，战斗瞬态用已有原创或授权明确的音效。

交付：近身绕圈、迎面相撞、贴墙闪避、闪避避伤、有效命中与挥空的有声实机片段。

## 第三步：招式变化

按用户后续确认：左键单次横劈，右键纵向重砸。两招明确取舍，不做自动无限连段。

- 左键横劈保留常用攻击的 40 伤害、24 体力与 0.8333 秒动作时长。
- 右键重砸首版为 55 伤害、34 体力、1.1 秒，前摇 0.55 秒，有效段 0.55–0.73 秒。
- 两招各自武器扫掠、每次攻击最多伤害一次；输入缓冲规则明确，不能在承诺阶段自由取消。

Boss 首轮以三个不同身体动作建立战斗，不再靠换方向挥武器充数：

| 招式 | 读招与应对 | 初测机制 |
|---|---|---|
| 承重重砸 | 膝盖下沉、举锤，侧闪反击 | 保留 1.05 / 0.22 / 1.25 秒及 35 伤害 |
| 近身踹击 | 重心移到支撑腿、膝盖抬起，退闪或绕侧 | 初测 0.8 / 0.22 / 1.0 秒，20 伤害；不用瞬发反制 |
| 拖锤短突进 | 侧身压低、锤头刮地冒火花，侧向避让 | 初测 1.2 / 0.55 / 1.5 秒，30 伤害；有限距离，受墙体阻挡 |

突进源动作需单独检查；预设不足时最多补一条文字生成动作并在 Blender 修正。不得把目录里没有的动作当成已经取得。

Boss 不读取玩家按键反制；按距离、冷却、朝向与已结束动作选招。攻击提交后锁定方向，不在出手期间高速追踪。踹击使用脚部扫掠，突进使用明确的前方接触体，重砸使用锤头轨迹，各自单次命中去重。

半血沿用机械过载提示，只新增一次清楚的接招变化，例如突进停止后重新蓄势重砸；追加动作可辨识，组合结束有完整恢复窗口。旧横扫可留作回退，本轮不继续堆招式数量。

## 第四步：在可读性基础上做炫酷

- 重砸落点：短促冲击尘、金属碎屑和少量火花；挥空不触发命中爆点。
- 拖锤：只在接触地面时有刮擦、火花和痕迹；停下后效果迅速消退。
- 玩家命中：明确金属撞击与短促命中停顿；命中停顿统一暂停相关动作阶段，不能偷改伤害/无敌计时。
- 二阶段：机械灯由暖黄转为过载红，蒸汽与节奏层加强。维持锤子和脚下照明，不用全屏白闪、浓烟或持续震屏遮挡读招。
- 镜头：重新校准大体型锁定构图、近身及贴墙碰撞。震动只发生在重击接触等关键点，幅度短而克制。

## 验收与回退

每步交付可玩的版本，再进入下一步；不能以导入成功、目录存在或机器人通关代替动作质量验收。

- 人物站立、移动、横斩、闪避、受击时没有明显身体互穿；贴墙与绕背连续操作不抖动、不穿墙。
- 主角两招有明显姿态和用途差异，保持正确持握和提灯位置。
- Boss 三招从前摇即可区分，每招都录到至少一次正常命中和一次成功避让；不使用无敌作弊作为公平性证据。
- 伤害接触与可见武器/脚部/突进身体轨迹一致，单次动作不重复扣血。
- 分别录制音乐开/关的战斗，确认实际声音可闻，而非只验证加载布尔值。
- 实机验证半血、死亡、R 重试、再次送电及胜利结尾。此前死亡重试未完成的记录不能当作本轮通过。
- 当前机器 1600×900，以 60 FPS 为目标采集帧时间，重点比较新增特效前后；其他机器及 30 分钟稳定性另行验证。
