## 3. 当前可玩实现与未完成事项

截至本记录，默认 SwordPass 路径已有：

- 左键横劈伤害 40、零体力；右键重击伤害 55、消耗 34；闪避消耗 28。旧基线模式仍可能使用旧规则。
- WASD 常速跑，Ctrl 慢走，Shift 快跑；战斗/锁定切到持剑戒备与战斗移动。Tab 锁定、E 交互、空格闪避、R 重试。
- 独立长剑、剑鞘，探索背负，战斗握持；玩家伤害按剑刃分段扫掠，每次攻击最多命中一次。

- 沿用已有命中停顿、火花、光效、震屏、合成音效与 Suno 音乐。本次人物接入没有重新制作音乐或取得新的音乐授权。

人物躯干约 31,198 三角面，披风约 1,664 三角面；保留 2K 颜色、金属/粗糙度和法线源贴图。**这只是可玩首版，尚未达到三视图精度。**

明确未完成：脸部相似度和精修、自然兜帽/披风褶皱与垂坠、独立手指动画、所有极端姿态穿插修正、全方向脚底贴合、动作衔接的主观体验验收。披风是独立蒙皮，不是布料模拟；握持是静态手套形变；本轮没有新购翻滚动画，继续使用既有适配动作。

## 4. 战斗通用化：讨论过，但没有实施

用户询问当前战斗是否能供后续场景复用。已给出的判断是：可以沿用规则和资产，但现在仍围绕单一守井者耦合，不能“换模型就得到新 Boss”。

现状证据：`AshWellCombatCharacter` 直接保存 `AAshWellWarden`、创建竞技场和 Boss、判断命中对象是否为 Warden，并包含送电、结束和升降机交互。骨架适配中还有根节点、镜像和手骨的特殊约定。

提出的下一步建议只有三项，**未实施，也未获得本轮新增实施指令**：

1. 统一可锁定、可受伤、死亡状态的敌人接口，使玩家不依赖具体 Boss 类。
2. 将动画、前摇、伤害窗口、恢复、体力、声音和效果放进招式配置。
3. 让关卡负责送电、开门与剧情；战斗只报告遭遇开始和胜负。

建议验收方式：增加一个简单第二种敌人，不修改玩家核心代码，也能锁定、攻击、闪避并击败它。不要把这段讨论写成“通用战斗框架已完成”，也不要据此自行开始大规模重写或引入完整技能系统。

## 5. 原创模型与现成动作：实际用了什么

本轮采用：三视图 → 去掉披风/背剑的绑定参考图 → Meshy 底模和自动绑定 → Blender 转换骨架/权重 → 社区动作重定向 → 长剑关键姿态、握持与伤害适配 → UE 实机验证。

- 六种基础移动/戒备使用已在项目中的 Quaternius Standard CC0 库；本地授权见 `SourceAssets/AnimationTrial/License.txt`。本地 Standard 为 45 个动作，不要把完整产品的宣传数量都称为免费库数量。
- 横劈和重击上身做了本地关键姿态和双段 IK 目标适配，不是只把同一挥动旋转方向。
- Meshy 随绑定提供的走/跑 GLB 已下载，但当前游戏走跑不是它们。
- Mixamo、Epic Game Animation Sample 曾讨论为可用方案，本轮没有下载接入或整体迁移。Kevin Iglesias 免费包也不能写成已接入。
- 原创角色不等于所有动作必须从零手搓；但重定向不能自动保证握持、脚底、根运动、布料和攻击接触正确。

## 7. 这轮最容易遗失的技术经验

| 现象或约定 | 处理和边界 |
|---|---|
| FBX 骨架不兼容 | 既有目标骨架是 `/Game/AshWell/Intro/Characters/SK_Intro_Protagonist_Skeleton`；Armature 对象根名必须为 `SK_Intro_Protagonist_Rig`。Blender 多场景 `.001` 重名可能破坏导出根名。 |
| 左右与尺度 | 玩家组件 Y 轴负缩放，武器实际跟随 `hand_L`；不能只按骨名字交换左右。既有动画根缩放为 100，握持偏移只使用位置和旋转，不继承骨骼的 100 倍缩放。 |
| 长剑轴向 | 本轮 UE 导入长轴为 +X，剑刃有效段为距握持原点 14–101 cm；旧锤子的轴向不能照搬。 |
| 跑动时人物消失 | 原始导入边界约米/厘米差 100 倍，实际蒙皮身体约 180 cm；已经添加实测边界扩展。不能只验证骨骼高度就认定不会被视锥剔除。 |
| 身体大块灰白与碎片状明暗 | 无光照颜色贴图正常，常规蒙皮切线光照异常；变形后世界位置导出的几何法线能消除主要亮斑。当前是局部材质兼容处理，不是已经彻底修好底层骨架或 UE。源法线图保留但未作为当前表面法线。近景精修应重整骨架单位和切线数据。 |
| 材质槽 | 重导入的渲染 section 曾指向材质索引 1；只保留槽 0 会出错。当前给两个槽都赋材质。 |
| 重导入单位不稳定 | 本轮导入阶段显式选 legacy FBX（编辑器会话设置），同时校验动画根缩放、时长和实体边界。不要只看导入参数。 |
| 动画播放速度未生效 | 自定义单节点派生实例在 Blueprint 模式下，`GetSingleNodeInstance()` 曾返回空；当前从 `GetAnimInstance()` 转换后设置速率。 |
| 运动叠加 | 既有 Meshy 翻滚水平根位移已移除，移动由游戏代码负责；重新导入后检查不要再叠加一次。 |
| Blender 中文界面 | Principled BSDF 节点按类型 `BSDF_PRINCIPLED` 查找，不依赖英语节点显示名；操作前核对当前 scene、active object、选择集。 |
| 编辑器启动卡住 | 本轮曾见 HomeScreen 枚举最近项目时卡在 `__opendir2`；该次启动使用 `-ini:Engine:[ConsoleVariables]:HomeScreen.EnableHomeScreen=0` 绕过。不是全局关闭功能，也不是每种启动失败都由它引起。 |
| 编辑器退出报错 | 既有项目级 ICU/Slate 延迟回调退出处理保留在 `AshWell.cpp`。需区分游戏进程、编辑器和崩溃报告器；不要关闭报告器来假装修复。详细证据见较早技术交接和 `Docs/Verification/EditorExit/`。 |

可重复运行的源脚本：`build_sword_motion.py`、`build_traveller_sword.py`、`prepare_traveller.py`、`chapter01_swordassets.py`、`import_traveller.py`。Blender 脚本有明确输入对象前提，不是对任意打开文件都可直接执行。
